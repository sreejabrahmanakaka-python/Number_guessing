🎯 Number Guessing Game

📌 About the Project

The Number Guessing Game is a simple Python project where the computer generates a random number and the player tries to guess it.

The player can choose from three difficulty levels and gets a maximum of 10 attempts to guess the correct number.

🎮 Difficulty Levels

Level| Number Range| Attempts
Easy| 1 - 50| 10
Medium| 1 - 100| 10
Hard| 1 - 1000| 10

⚙️ How It Works

1. Select a difficulty level.
2. The computer generates a random number.
3. Enter your guess.
4. The game provides a hint:
   - ⬇️ Too Low – Try a higher number.
   - ⬆️ Too High – Try a lower number.
5. If the correct number is guessed, the game displays a congratulation message.
6. If all 10 attempts are used, the game ends and displays the correct number.

🛠️ Technologies Used

- Python
- Random Module

▶️ How to Run

Make sure Python is installed on your computer.

Open the project folder in VS Code or a terminal and run:

python number_guessing_game.py
